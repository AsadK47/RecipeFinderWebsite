# RecipeFinder Website 🌟

**Live at [recipefinder.uk](https://recipefinder.uk)**

A beautiful, modern landing page for the RecipeFinder iOS app. Clean design, smooth animations, and fully GDPR-compliant.

---

## ✨ What's Inside

- 🎨 **Gorgeous gradients** matching the app's teal theme
- 📱 **Fully responsive** - looks perfect on any device
- 🎭 **Smooth animations** - fade-ins, floating elements, and micro-interactions
- 📧 **Email signup** for launch notifications
- 🍪 **Cookie consent** with Accept/Reject options (GDPR-ready)
- ⚖️ **Legal pages** - Privacy, Terms and Cookies
- ⚡ **Lightning fast** - plain HTML, CSS and JS
- 🌓 **Light/Dark themes** with smooth transitions

---

## 🎨 Customization

**Change Theme Colors:**

Edit the CSS variables in `styles.css`:

```css
:root {
    --teal-bright-light: rgb(20, 184, 166);
    --teal-medium-light: rgb(45, 155, 180);
    --teal-deep-light: rgb(59, 130, 246);
}
```

---

## 🍪 Cookie Compliance

The site uses **minimal cookies**:
- **Preferences:** Theme choice (light/dark mode)

Visitors choose Accept or Reject. With Reject, the theme toggle works for the current visit and nothing is stored.
